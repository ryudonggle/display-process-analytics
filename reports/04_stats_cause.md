# 04. 통계 기반 원인 분석

> 사용 스킬: `statistical-analysis`(검정 선택, 효과크기, 다중비교·심슨 역설·교란 주의)
> 코드: `src/s04_stats.py` · 결과: `reports/04_univariate_tests.csv`, `04_adjusted_logit.csv`, `04_stats_summary.json` · 그림: `figs/04_binned_defect.png`

## 0. 분석 설계

| 단계 | 방법 | 이유 |
|---|---|---|
| 단변량 | Mann-Whitney U + 효과크기 r(rank-biserial) | 분포가 이산적이고 치우쳐 있어 비모수 검정 |
| 다중비교 | Benjamini-Hochberg FDR (q < 0.05) | 151개 변수를 동시에 검정 |
| **층화 검정** | 구 레시피(~2023-09) / 신 레시피(2023-10~) 각각에서 재검정 | 레시피 변경 + 시간 추세에 의한 **심슨 역설** 차단 |
| 범주형 | 카이제곱 + Cramér's V | |
| 교란 통제 | 로지스틱 회귀(변수 + 레시피 + 경과일 + 모델 + 라인) → 1SD당 오즈비 | |

**판정 기준 — "견고한 원인 후보"**: 전체에서 유의하고, **두 레시피 안에서도 각각 유의하며 방향이 같은** 변수.

| 결과 | 개수 |
|---|---|
| 검정 변수 | 151 |
| 전체 기준 유의 (q<0.05) | 110 |
| **견고 (양쪽 레시피 모두 유의, 같은 방향)** | **28** |
| 전체에선 유의하지만 층화하면 사라짐 (심슨 의심) | 84 |

→ 전체 데이터만 보고 "유의하다"고 했다면 **76%가 착시**였다. 대부분 "초기 기간 = 구 레시피 = 불량 많음"이라는 교란 때문이다.

## 1. 결정적 신호 — 규칙으로 바로 걸러지는 불량 (132건, 정밀도 99.2%)

| 신호 | train 건수 | 불량률 | 해석 |
|---|---|---|---|
| **총 리드타임(Dam→AutoClave) > 2시간** | 103 | **99.0%** | 정상 흐름은 약 30분. 2시간 넘게 정체된 제품은 사실상 전부 불량 |
| └ 특히 Fill2→AutoClave 대기 > 2시간 | 69 | 98.6% | **UV 반경화 후 합착·탈포 전 대기**가 길어지는 것이 문제 |
| **설비 라인을 바꿔 탄 제품** (Dam·Fill1·Fill2 번호 불일치) | 34 | **100%** | 재작업·우회 투입 이력 |
| Fill1 미도포 | 1 | 100% | |

- 둘을 합치면 train 132건 중 131건이 불량이다. **전체 불량의 5.6%를 오탐 1건으로** 잡는다.
- test에서도 52건에 해당한다.
- **현장 조치**: "Fill2 이후 2시간 내 탈포 투입" 인터락을 걸고, 라인 간 이동품은 별도로 관리한다.
- 공정 해석: 반경화된 레진이 오래 대기하면 점도·경화도가 변해 합착 때 기포를 가두고, 탈포에서도 제거되지 않을 가능성이 높다.

## 2. 견고한 공정 원인 후보 (레시피 층화 후에도 유지)

### 2-1. Dam 가벽 도포 조건 — **헤드가 빠르고 토출이 짧으면 불량 ↑** ⭐ 1순위

규칙 해당 건을 제외하고, 설정값별 불량률(n≥150)을 보면 아래와 같다.

| Dam Stage2 헤드 이동속도 | 구 레시피 | 신 레시피 |
|---|---|---|
| 4000 | – | **3.95%** (n=4,002) |
| 5000 | **3.44%** (n=1,192) | 4.90% |
| 5300 ~ 6500 | – | 4.1 ~ 5.1% |
| 8000 | – | **6.36%** |
| 9000 | 6.90% (n=11,775) | – |
| 12000 | **8.22%** (n=3,407) | – |

| Dam Stage2 토출 시간 | 구 레시피 |
|---|---|
| 3.9초 | **8.25%** (n=3,296) |
| 4.9초 | 6.86% (n=10,269) |
| 8.4초 | **3.41%** (n=1,174) |

- **두 레시피 모두에서 단조 증가**한다. 속도 4000~5000일 때 3.4~4%, 8000~12000일 때 6.4~8.2%로 약 **2배 차이**가 난다.
- 교란 통제 로지스틱 결과도 같다. 이동속도 1SD 증가 시 **불량 오즈 1.25배**(95% CI 1.16 ~ 1.35), Stage2 토출 시간 1SD 증가 시 **0.77배**(0.71 ~ 0.83).
- **해석**: 헤드가 빨리 지나가고 토출 시간이 짧으면 **Dam(가벽)이 얇거나 끊겨**, 내측 Fill 레진이 새거나 합착 때 공기가 들어간다(→ 기포).
- Stage2는 디스플레이 두 장 사이의 중앙 구간으로 보인다(좌표상 X 중간값).

### 2-2. Fill1 헤드 좌표 편차 — 정렬 불량 신호

- `Fill1 좌표 편차 절대합`: 교란 통제 후 OR **1.15/SD** (1.12 ~ 1.18), 양쪽 레시피 모두 유의
- Fill1 Stage2 도포량·토출 시간도 견고(OR 1.09/SD). 기준(3.42)보다 많이 도포한 3.61 ~ 3.70 구간에서 5.7 ~ 6.5%
- Dam Z(Stage1) 높이 편차는 단변량으로는 1위였지만, **교란을 통제하면 효과가 사라진다**(OR 1.00, p=0.98) → 원인에서 제외

### 2-3. UV 경화·탈포 (hwp 가설 검증)

| 가설 | 결과 |
|---|---|
| UV 경화 조건이 기포에 영향 | 신 레시피에서 Fill2 경화 속도 **45(느림 = UV 조사 많음)일 때 6.57%** vs 50일 때 4.28%. 방향성은 있으나 n=2,312로 적고 구 레시피에서는 확인 불가 → **약한 근거** |
| 탈포 압력·시간 | 탈포 압력×시간 총합은 전체 기준으론 유의했지만 **층화하면 사라진다** → 레시피 변경과 겹친 착시 |
| 챔버 온도 | 46℃ 이하 저온에서 8 ~ 11%로 높지만 구간이 작음(n<400) → 관찰 대상 |

## 4. 레시피 변경 효과는 "진짜"인가?

- 전체로 보면 구 7.3% → 신 4.8%로 크게 줄었다.
- 하지만 **변경 직전·직후 2개월(2023-08 ~ 11)만 비교하면 5.3% vs 4.8%, p=0.23으로 유의하지 않다.**
- → 불량률 하락은 **대부분 2023-05 ~ 07의 초기 불안정 구간 효과**다. 레시피 변경 자체의 기여는 크지 않거나 불확실하다.
- 대신 **각 레시피 안에서도 Dam 이동속도·토출 시간이 불량을 가른다**는 점이 더 실행 가능한 결론이다.
