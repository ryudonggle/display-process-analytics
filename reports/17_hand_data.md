# 17. 수기 측정 데이터(hand_data) 분석

> 코드: `src/s17_hand_data.py` · 결과: `reports/17_run.log`, `17_hand_data_logit.csv`
> 원본: `hand_data.xlsx` (현장 수기 입력)

## 0. 요약

- 설비 로그에 없던 **UV 경화 에너지(mJ)**를 처음 확인했다. Fill2 경화 속도가 느릴수록(45) UV 에너지가 높고(1,751mJ) 불량률도 높았다(7.3%).
  - 16단계의 "경화 속도 45 = 불량 6.5%"가 **UV 과조사**와 연결된다는 정황 근거다.
- 새 후보로 **Fill 두께**가 나왔다. 200 이하일 때 2.7%, 220~235일 때 6.9%로, 시간대 군집 통제 후에도 유의했다(OR 1.29/SD, p=0.013).
- 기간이 21일이고 속도 45 구간이 3월 하순에 몰려 있어 **날짜 효과와 분리되지 않는다.** 원인 확정이 아니라 **방향 확인과 데이터 수집 제안의 근거**로 쓴다.

## 1. 데이터

| 항목 | 내용 |
|---|---|
| 기간 | 2024-03-19 ~ 04-28 중 **21일** (작업일 일부만 기록) |
| 기록 단위 | 하루 5개 시간대(08:00–10:30, 10:45–12:00, 13:00–15:00, 15:15–18:00, 18:30–20:00) |
| 유효 기록 | 105행 중 **81개 시간대** (나머지는 빈칸. 주로 18:30–20:00) |
| 항목 | Dam 두께·Fill 두께(하루 1회), **UV 경화 에너지(mJ)·출력(mW)**, 라인 온도·습도(시간대마다), OCR gap(라인 #1·#2 × Stage 1~3) |

### 제품과 연결하는 방법

- 제품의 **Fill2 시각**이 기록 시간대(시작~끝) 안에 들면 그 시간대 값을 붙였다. UV 경화가 Fill2 공정에서 일어나기 때문이다.
- OCR gap은 제품이 탄 라인(#1/#2)의 값을 골랐다.
- 대상은 16단계와 같은 기준이다. 규칙 해당(2시간 대기·라인 변경·Fill1 미도포)과 Dam Y(Stage2) 음수 편차 제품은 뺐다.

| 단계 | 건수 |
|---|---|
| 기간 안 train 제품 | 4,365 |
| 기록 시간대에 연결됨 | 3,548 (불량 195) |
| **규칙·Y 음수 편차 제외 = 분석 대상** | **3,436 (불량 176, 5.12%) · 78개 시간대** |

### 분석 방법

- 같은 시간대의 제품은 측정값을 공유한다. 그래서 제품 단위로 검정하면 표본이 부풀려진다.
- 로지스틱 회귀(변수 표준화 + 라인)에 **시간대 군집 표준오차**를 적용해 보수적으로 판단했다.

### 2-2. UV 경화 에너지 ⭐

**경화 속도와 UV 에너지의 대응**

**UV 에너지 구간별 불량률**

| UV 에너지 (mJ) | n | 불량 | 불량률 |
|---|---|---|---|
| ≤ 1,600 | 135 | 7 | 5.19% |
| 1,600 ~ 1,640 | 484 | 23 | 4.75% |

| **1,700 ~ 1,800** | **1,033** | **72** | **6.97%** |
| > 1,800 (오타 의심, §4) | 90 | 2 | 2.22% |

- **경화 속도가 느리면 UV를 더 오래 쬐어 에너지가 약 100mJ 높다.** 로그의 경화 속도를 UV 에너지의 간접 지표로 써도 된다는 근거다.
- 1,700mJ를 넘는 구간에서 불량률이 1.6배다. hwp 문서의 가설("UV 에너지가 기포의 주요 인자")과 방향이 맞고, **과경화 쪽이 위험**하다.
  - 메커니즘(추정): 과경화된 레진은 수축 응력이 커지고 합착 때 유동성이 떨어져 기포를 가둔다.
- **그런데 통제 로지스틱에서는 유의하지 않다(p=0.92).** 이유는 두 가지다.
  1. 관계가 직선이 아니다. 낮은 구간(≤1,600)도 5.2%로 조금 높아 U자에 가깝다.
  2. 고에너지(속도 45) 구간이 **2024-03-18 ~ 28**에 몰려 있어, 날짜에 따른 다른 요인과 분리되지 않는다.
- → **"UV 과조사가 불량을 높인다"는 정황 근거**로 쓴다. 확정하려면 같은 기간에 경화 속도를 바꿔 보는 시험이 필요하다.

### 2-3. Fill 두께 (신규 후보)

- 두꺼울수록 불량률이 오르다가 235를 넘으면 조금 내려온다. 군집 통제 후에도 유의한 **유일한 변수**다.
- 16단계의 "Fill1 Stage2 도포량이 기준보다 많으면 불량 ↑"와 같은 방향이다. 도포량 → 두께 → 불량으로 이어지는 경로일 수 있다.
- 다만 하루 1회 측정이라 실제로는 **날짜 단위 21개 값**이다. 날짜 효과와 섞였을 수 있다.

## 3. 기존 분석과의 연결

| 기존 결론 | 수기 데이터로 달라진 점 |
|---|---|
| 00 요약: "UV 실측값이 없어 판단 보류" | **경화 속도 ↔ UV 에너지 대응 확인.** 과조사 구간 불량 1.6배 → **방향 확인** |
| 16단계: Fill2 경화 속도 45일 때 6.5% | 속도 45 = UV 약 1,750mJ. **간접 지표의 의미가 확인됨** |
| 16단계: Fill1 도포량 많으면 불량 ↑ | Fill 두께도 같은 방향(OR 1.29). 도포량 → 두께 경로 후보 |
| 데이터 수집 제안: UV 실제 조사량 | 21일 수기 기록만으로도 신호가 보였다 → **자동 수집의 근거** |
