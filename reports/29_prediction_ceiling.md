# 27 ~ 29. 분석 결과로 예측 성능을 올릴 수 있나 — 정보의 천장

> 코드: `src/s21_more_rowfeats.py`, `s27_predict_from_findings.py`, `s28_stream_model.py`, `s29_feedback_and_simple.py`
> 결과: `reports/21 · 27 · 28 · 29_*.json`, `*_run.log` · 그림: `figs/28_stream_model.png`, `figs/29_feedback.png`

## 0. 요약

> **분석에서 찾은 원인을 피처로 넣고, 실시간 로그와 빠른 검사 결과까지 가정해도 미래 예측은 무작위의 약 3배(train 전체)·2배(알려진 원인 제외)에서 멈췄다. 천장은 모델이 아니라 정보에 있다.**

## 1. 평가 방법

- **월별 롤링**: 2023-12 ~ 2024-04 각 달을 "미래"로 두고, 그 이전 전체로 학습했다(5회 평균, 시드 2개).
  - 한 구간(3 ~ 4월)만 보면 신뢰구간이 ±0.01로 개선 폭보다 커서 바꿨다.
- **정보 가정**을 단계별로 늘렸다.

| 가정 | 쓸 수 있는 정보 | test 파일만으로 생성 |
|---|---|---|
| 기준 | 제품 한 행 + 미리 정한 상수 | 가능 |
| **B** | + 실시간 생산 로그(라벨 없음): 탈포 배치, 탈포기 휴지, 대기 중 라인 정지, 하루 순번, 작업지시 진행 | 불가 (현장 로그 필요) |
| B+ | + 전날까지의 검사 결과 (작업지시·라인 과거 불량률) | 불가 |
| B + 검사 N시간 후 | + 탈포 N시간 뒤 나오는 검사 결과 (N = 2 · 4 · 8 · 24) | 불가 |

- **누수 검증**: 라벨을 뒤집어도 그 시점 이전 피처가 변하지 않는지 자동으로 확인했다 → 모두 통과

## 2. 결과 (롤링 평균 PR-AUC, 괄호는 무작위 대비)

| 시도 | train 전체 | 9월+ 알려진 원인 제외 |
|---|---|---|
| **기준 (test 한 행)** | **0.148 (3.08배)** | **0.093 (2.12배)** |
| + 달력 · 교대 · 팔레트 · 카운터 (21단계, 한 구간 기준) | 변화 없음 | 하락 |
| + 견고 조건 플래그 (챔버 저온 · UV 45 · Dam 고속) | 0.141 | 0.100 → 0.100 |
| **B: 실시간 로그** | 0.150 (3.11배) | 0.091 (2.07배) |
| B+: 전날 검사 결과 | 0.151 (3.12배) | 0.092 (2.09배) |
| B + 검사 2시간 후 | 0.149 (3.10배) | 0.091 (2.08배) |
| B + 검사 8시간 후 | 0.151 (3.14배) | 0.091 (2.08배) |
| B + 검사 24시간 후 | 0.151 (3.12배) | 0.094 (2.14배) |
| 단순 로지스틱 (견고 조건 15개) | 0.146 (2.99배) | **0.095 (2.11배)** |
| 작은 LightGBM (강한 규제) | 0.142 (2.93배) | 0.087 (1.98배) |

- 어떤 정보를 더해도 차이는 **±0.005 안**이다. 신뢰구간 안의 흔들림 수준이다.
- **단순 로지스틱(조건 15개)이 복잡한 모델과 거의 같다.** 9월 이후 집단에서는 상위 3% 정밀도가 가장 높다(14.2% vs 12.9%). 현장에 설명하기 쉬운 모델로 같은 성능을 낼 수 있다.

## 3. 왜 안 오르나

| 이유 | 근거 |
|---|---|
| **강한 원인은 소수 제품에만 해당** | 작은 배치 3%, 챔버 저온 1%. 그 안에서 3배여도 전체 순위는 거의 그대로 |
| **로트 효과는 예측에 쓰기엔 늦다** | 작업지시 대부분이 하루 안에 끝나고, 두 라인 동시 악화도 **당일**에 일어났다. 2시간 뒤 결과를 알려줘도 개선 없음 → 같은 작업지시 안에서 불량이 시간적으로 연달아 나오지 않는다 |
| **모델이 이미 핵심 신호를 쓰고 있다** | 리드타임, 설정값 원값에 배치·UV·속도 정보가 상당 부분 들어 있다 |
| **남은 불량은 로그에 없는 정보** | 불량 유형(기포·정렬·크랙), 자재 로트, 챔버·UV 실측값 |

## 4. 결론과 의미

- **"모델을 더 다듬어도 소용없다"는 것을 8가지 실험으로 보였다.** 성능의 천장은 정보다.
- 그래서 현장 가치는 두 갈래다.
  1. **진단**: 찾은 원인(작은 배치, 챔버 저온, UV 과조사, Dam 고속, Y 정렬)을 **설정·운영 기준으로 바꾸는 것**. 예측이 아니라 예방이다.
  2. **데이터**: 천장을 올리려면 **불량 유형 라벨, 자재 로트 번호, 챔버·UV 실측 곡선, 정지 사유 코드**가 필요하다.
- 예측 모델은 **단순 로지스틱(15개 조건)**을 권장한다. 성능은 같고, 각 조건이 왜 위험한지 현장에 설명할 수 있다.
