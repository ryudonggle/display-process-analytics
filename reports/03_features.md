# 03. 피처 엔지니어링

> 근거: 1단계 hwp 공정 설명(도포 → UV 경화 → 합착 → 탈포)과 2단계 발견(레시피 변경, 라인별 좌표 기준 차이)
> 코드: `src/s03_features.py` · 사전: `reports/03_feature_dict.json` · 단변량 신호: `reports/03_feature_auc.csv` · 결과: `data/features.parquet` (173열)

## 1. 만든 피처 (73개)

| 그룹 | 피처 예 | 공정 가설 |
|---|---|---|
| **레진 도포** (Dam·Fill1) | 총 도포량, 총 토출 시간, 토출률(양/시간), Stage2 비중, Stage1-3 비대칭, Dam/Fill1 도포량 비, Fill1 미도포 | 도포량·균일성이 부족하면 기포가 생기고, 과하면 넘침·수축(Crack)이 생긴다 |
| **UV 경화** (Dam·Fill2) | 경화 이동거리, **경화 시간 = 거리/속도 (UV 조사량 대리변수)** | hwp: "UV 에너지가 기포의 주요 발생 인자" |
| **Dam 헤드 이동** | 이동속도 평균·편차, 도포량/이동속도(선당 두께), 두께 편차 | 빠르게 이동하면 가벽이 얇아져 내측 레진이 넘친다 |
| **탈포** (AutoClave) | 단계별 압력×시간, **총 압력×시간(탈포 에너지)**, 총 시간, 온도×시간, 압력 상승폭 | hwp: "압력과 시간에 따라 기포가 남거나 제거된다" |
| **좌표 정렬** | 라인·모델 중앙값 대비 편차(26개), 공정별 편차 절대합, Stage1-3 위치차 | Misalignment(정렬 불량) |
| **시간** | 공정 간 대기시간(Dam→Fill1→Fill2→AutoClave), 총 리드타임, 시각, 요일, 경과일, 신규 레시피 여부 | 레진이 오래 대기하면 점도가 변하고, 시간 추세를 통제해야 한다 |
| **작업지시** | 규모, 투입 순서, 생산 기간, 접두어·차수, 생산 진행률, 택트타임 차 | 로트·자재 단위로 불량이 몰림(1단계) |

## 2. 단변량 신호 (불량 판별 AUC, 0.5 = 무작위)

| 순위 | 피처 | AUC | 방향 | 해석 |
|---|---|---|---|---|
| 1 | Dam Z(Stage1) 편차 | 0.582 | + | Dam 헤드 높이가 기준보다 **높을수록** 불량 ↑ |
| 2 | Dam 헤드 이동속도 평균 | 0.578 | + | **빠를수록** 불량 ↑ |
| 3 | Dam Y(Stage2) 편차 | 0.577 | − | |
| 4 | Fill1 X(Stage2) 편차 | 0.576 | + | |
| 5 | 경과일 | 0.572 | − | 초기일수록 불량 ↑ (시간 추세) |
| 7 | Dam 총 토출 시간 | 0.564 | − | 짧을수록(=도포량 적을수록) 불량 ↑ |
| 9 | Dam 도포량/이동속도 | 0.563 | − | **가벽이 얇을수록** 불량 ↑ |
| 12 | 신규 레시피 | 0.557 | − | 신규 레시피에서 불량 ↓ |
| 23 | 탈포 압력×시간 총합 | 0.546 | + | |

### 읽는 법
- **단일 변수로는 판별력이 약하다**(최대 0.58). 불량이 여러 요인의 조합으로 생긴다는 뜻이고, 변수 간 상호작용을 잡는 트리 모델이 필요하다.
- 상위 신호가 **"Dam 가벽 형성 조건"**(이동속도, 토출 시간, 선당 도포량, 헤드 높이)에 몰려 있다. 2023-10 레시피 변경(이동속도 ↓, 도포량 ↑)으로 불량이 줄어든 현상과 같은 방향이다.
- 다만 레시피·경과일·도포량이 **서로 얽혀 있다**(교란). 4단계에서 **레시피 그룹 안에서도 효과가 유지되는지** 따로 검정한다.
